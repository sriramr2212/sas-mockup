# Sri Aishwarya Sarees — Heritage Homepage

Editorial marketing site for Sri Aishwarya Sarees, built on TanStack Start.

- Homepage: `src/routes/index.tsx`
- Temples archive: `src/routes/temples.tsx`
- Scoped styles: `src/heritage-homepage/styles.css`
- Featured temples content: `src/heritage-homepage/temples.json` (newest first;
  index 0 = current month on the homepage, index 1 = previous month).
